Privacy Policy

Last updated: October 18, 2026

About the application

HA Drive Monitor is a personal, non-commercial application that monitors changes in Google Drive folders accessible to its authorized user.

Google Drive data

The application requests read-only access to Google Drive to identify images that have been added, modified, renamed, or deleted.

Data storage

The application stores file identifiers, names, folder paths, modification fingerprints and file links in a private GitHub repository to compare changes between scans.

Data sharing

Change notifications containing file names, paths and links are sent to the authorized user through Telegram. The application does not sell Google Drive data or use it for advertising.

Security and access

Access credentials are stored as GitHub Actions secrets. The application does not modify or delete Google Drive files.

Data retention

File metadata is retained while monitoring is active. The owner may delete the stored metadata and revoke Google access at any time.
